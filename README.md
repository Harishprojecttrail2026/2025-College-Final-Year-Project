# ANIME IOS APPLICATION

## Description
This iOS application provides detailed information about anime series, including episode-wise data and descriptions. A key feature of the app is the integration of the KOMMUNICATE SDK, which enables an in-app chatbot solution. The chatbot can be trained using documents such as Word files and supports scalable, pricing-based plans.

Additionally, the application is backed by a custom-built backend system, where dedicated APIs have been developed to serve episode-level data efficiently and reliably.

## Tech Stack
- SwiftUI
- Postman
- Xampp
- Kommunicate [SDK]

## How to Run
Run in the Xcode by unzipping the file from the repository.

## Features
- Contains API of the Anime's(limited) each and every episode
- Integrated a SDK to run the Chatbot
